# Architecture Documentation

Esta pasta reúne a documentação arquitetural descritiva do Project Mimikyu.

## Scope

Podem ser mantidos nesta área:

- visão de contexto do sistema;
- modelo lógico;
- modelo físico;
- componentes;
- integrações;
- fluxos;
- diagramas.

## Boundaries

Esta pasta não substitui:

- ADRs, que explicam por que decisões arquiteturais foram tomadas;
- Standards, que definem como padrões permanentes devem ser aplicados;
- documentos centrais, que estabelecem identidade, princípios e governança.

Documentos arquiteturais devem utilizar links relativos para os ADRs e Standards relacionados, evitando duplicar decisões ou regras.
